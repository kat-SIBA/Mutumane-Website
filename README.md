# Mutumane Kota 'N' Grilled Chicken - Web Application

A multi-page website built for **Mutumane Kota 'N' Grilled Chicken**, a local South African fast-food establishment specializing in loaded township kotas, flame-grilled chicken, salsa meals, and family combos.

---

## 📌 Project Overview

This project provides Mutumane Kota 'N' Grilled Chicken with a dedicated digital presence to showcase their brand, highlight full menu offerings with transparent pricing, provide operating hours and delivery area details, and streamline customer inquiries and order requests.

---

## 🎯 Business Challenges & Solutions

| Challenge | Solution Provided |
| :--- | :--- |
| **Repeated Phone Calls for Menu & Pricing** | Digital menu featuring items, sides, and prices cleanly laid out on the web. |
| **Order Errors During Peak Hours** | Structured online order request form with meal selections, topping checkboxes, and sauce choices. |
| **Limited Local Visibility** | Centralized web presence detailing location, 15km delivery radius, operating hours, and contact details. |
